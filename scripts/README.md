# netwave scripts

Workspace-level tools only: CI gates and toolchain helpers. Not part of any
published package. Cross-binding grading lives in
[`oracle/compare_cross.py`](../oracle/compare_cross.py). A dump that serves a
single subproject lives in that subproject's `scripts/`
(`core/scripts/dump.rs`, `python/scripts/dump.py`,
`typescript/scripts/dump.mjs`).

## Scripts

| `coverage_gate.py`           | coverage floor gate: reads a cargo-llvm-cov `codecov.json` (OR-merged line coverage) and fails below the floor; called once per report (core / python glue / native glue)                                                                                                                                                                                                                                                                                                       | `python3 scripts/coverage_gate.py coverage/coverage-core.json 100` |

| `run/test_cross.sh`          | cross-binding test entry: python glue build + stub_gen + four-end dump + grading + cross-end vocabulary gates — the single source of cross-binding test command details; local `pnpm test:cross` and the CI node job both call it (needs `uv` + maturin; prints the install command and fails if missing)                                                                                                                                                                       | `bash scripts/run/test_cross.sh`                                   |

The `check_*.py` gates are not run individually — they are wired into the
aggregate commands defined in [`package.json`](../package.json):
`pnpm check:md` (markdown links/anchors + code-span detection),
`pnpm check:meta` (CI completeness, license, vocab, comment hygiene, proposal
sections, version consistency, Python hygiene). Cross-binding dump + compare
runs via `pnpm test:cross` (a test gate: it executes all four ends).
`pnpm check` chains the static gates.

The cross-binding pipeline (`pnpm test:cross`) and the grading contract
live in [CONTRIBUTING.md](../CONTRIBUTING.md) and
[oracle/README.md](../oracle/README.md); tolerance tiers are defined in the
[governance spec](../openspec/specs/project-governance/spec.md).
