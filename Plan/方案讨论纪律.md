# 方案讨论纪律 —— 治"反复返工"（临时纪律，未转正）

五类返工根因：看不懂术语、方案过复杂、越权执行、绕回已定裁决、不查现成方案。
本文件是**临时纪律**，默认不转正，见[转正判定](#转正判定)。

## 硬护栏（唯一铁律）

- **动词 = 授权全集**：只执行人明确点名的动作；未点名的动作——改文件、建文件、
  删文件、git commit——一律禁止执行。
- **"研究 / 探讨 / 该不该"类题目 = 只出文字答案**并附原因；动手执行即越权。
- **"实施"不等于"改代码"**：指执行此前讨论定下的动作——定的是改文档就改文档。
- **此前已定裁决 = 已获授权**：直接执行，不必每次重新确认。
- **规矩闸门自动执行**：AGENTS.md / spec 规定必做的闸门（`pnpm check`、
  `pnpm check:md`、测试、波及面同步）即使题目没点名也必须跑，漏掉即违规。
- **不确定必须问**：题目语义有歧义、或会动 spec / 公开 API / 数据布局时，
  必须问人，不许自己选。提问不需要口令——提问不改动任何东西。
- **找事实归 agent，拍板归人**：能从环境查到的不许甩给人；决定权不替人行使。

## 最小规则原则（官方实证）

"给 AI 规则越多越好"已被官方否定——护栏要少而硬，缰绳要松：

- 追求"能完整表达预期行为的**最小信息集**"（"do the simplest thing that
  works"），而非穷举规则清单。
- **通用指令优于手写步骤**（"Prefer general instructions over prescriptive
  steps"）；把边缘情况一长串塞进提示词被官方点名不推荐，改用少量典型示例。
- 模型越强，越应减少人类过程干预；最成功的 agent 实践用简单可组合模式，
  而非复杂框架。

出处：[Anthropic：Effective context engineering for AI agents](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)、
[Anthropic：Building effective agents](https://www.anthropic.com/research/building-effective-agents)、
[Anthropic Claude 提示词最佳实践](https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/claude-4-best-practices)。

**推论**：程序性仪式（阶段档位词表、固定轮次格式、自检行）退役——它们诱导
agent 拿关键词对表格而非审题；本文件只保留上述护栏与台账机制。

## 最小方案默认

- 首轮方案 = **一个能独立验证、独立回滚的最小增量**；范围不够由人说"扩大"再扩。
- 方案必须附**"本次明确不做"清单**：agent 想顺手加的东西列出来给人砍，不许藏。
- 方案先查同生态现成做法——规则唯一正文见
  [AGENTS.md](../AGENTS.md)「方案先查现成做法」，本文件不重述。

## 裁决台账

- **拍板即记**：会话内每拍板一条，agent 立刻记"已定裁决"（决定内容）；
  提新方案前**必须先复述台账逐条对齐**，防止绕回。
- 说不出裁决原话 = 没说过——不许替人"记得"，不许替人补拍板。
- **持久落点**：已立项 → 该 change 的 `design.md`「Decisions」节，
  不另建 `decisions.md`——同一事实只存一份正文；
  未立项 → 并入既有 `Plan/` 文件的"已定裁决"节；都没有才新建 `Plan/<话题>.md`。
- **不直写永久 spec**：`openspec/specs/` 与 lessons-learned 不接受台账直写。

## 转正判定

- **台账条目**：change 归档时集中判——agent 列出全部条目 + 建议去向
  （进 spec / 留 Plan / 删），人逐条圈定。**默认临时**：
  未获明确点头的条目随 Plan/ 清空消亡，沉默 = 不转正。
- **本纪律整体**：[AGENTS.md](../AGENTS.md) 只留 3-5 行指针（写指针属执行
  动作，须人点名）；升格 governance spec 须随某次 change 归档逐条判定，
  否则终态随 Plan/ 清空。
- 永久区入口只有一个：change 归档。

## 长会话止损

三条件**任一命中**即写交接笔记（含裁决台账）并建议开新会话，不许恋战
（数字为启发式，非精确阈值）：

- 单会话超过 40 轮
- 跨天继续同一话题
- 同一话题被人工纠正满 3 次

## 待逐项讨论（附建议）
