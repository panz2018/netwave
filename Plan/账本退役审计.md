## 三类退出判据

一条 LL 满足任一条即可退出账本（正文迁出或删除，事故证据靠 git log）：

1. **已铁律化**：规则已被 governance spec 某铁律/元规则完整覆盖 →
   账本正文删除，必要时把事故理由并入该铁律的 rationale。
2. **已门禁化**：规则已被某脚本 / CI 闸门强制（违规直接红）→
   账本正文删除，门禁脚本即执行者。
3. **一次性环境事实**：只对本机、某工具版本或某次迁移有效，不跨机器复用 →
   账本正文删除。

不满足任一判据 = **保留账本**（仍是活口诀、无门禁兜底、跨机器有效）。
