## typescript（napi / wasm / worker）

- [ ] napi：`Buffer::from` 零拷贝内部 `mem::forget`；`from_raw_parts` 重建时
  capacity 必须传 `v.capacity()*16`，否则 double-free
- [ ] napi：直接返回 `Vec` 会退化为逐元素 JS Array，必须显式 `Buffer` 类型
- [ ] napi CLI 旗标：`--manifest-path`（非 `--cargo-cwd`）、`--format commonjs`
  （非 `cjs`）——版本漂移点，升级后必查
- [ ] wasm：`js_sys::Memory` 不存在，用 `js_sys::WebAssembly::Memory`
- [ ] wasm：web target 选型原因（bundler glue 在 node/vitest 不可加载，
  web glue 两端通用）
- [ ] wasm：init 传 `{module_or_path: bytes}`（Node 无 `fetch file:`）；
  字符串/URL 形态已废弃
- [ ] wasm：沙箱下载不了 binaryen → `wasm-opt = false`（CI 恢复默认）
- [ ] worker：wasm 线性内存绝不能 transfer（detach 实例）；
  `.slice()` 复制进新 ArrayBuffer 再 transfer
- [ ] 壳文件体系：`publish_shell.mjs` 的 `../dist/` → `./` 重写规则
