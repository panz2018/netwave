## 待办 1：AGENTS.md 的 corepack 条款疑似死条款

- **现象**：根 `AGENTS.md`「终端命令规范（防卡死）」仍写着
  「corepack 命令必须带 `COREPACK_ENABLE_DOWNLOAD_PROMPT=0`」。
- **疑点**：knowledge 侧实测 Node ≥ 25 起官方不再随带 corepack
  （见《知识库升级指南》§6，2026-10-24 记录 v26.12.1 无 `corepack` 命令）。
  若本机默认 Node 已 ≥ 25 且未单独装 corepack，则该条款在本机永不触发，
  属死条款。
- **核实命令**（执行前确认当前默认 Node 与 corepack 是否存在）：

  ```bash
  bash -ic 'node -v; command -v corepack || echo "no corepack"'
  ```

- **处置分支**：
  - 若 corepack 确实不存在 → 删除该条，或改写为「若某 Node 版本装有
    corepack，则其命令须带 `COREPACK_ENABLE_DOWNLOAD_PROMPT=0`」。
  - 若仍装有 corepack（如为按 `packageManager` 钉版而单独 `npm i -g corepack`）
    → 保留该条，并在本条注明保留原因。
- **注意**：CI 用 pnpm 的 action-setup（版本见 `.github/workflows/ci.yml`），
  不经 corepack，本待办只影响本机终端规范，不影响 CI。
