# linux-arm64 绑定测试格（延后，2026-11-13 人工裁决）

## 背景

CI 矩阵现状：rust job 有 `linux-arm64`、wasm job 有 `ubuntu-26.04-arm`，
唯独 python / node 两个绑定 job 没有 arm64 格。绑定产物（`.so`/`.node`）
的 aarch64 ABI 无人验证；开发机即 arm64，缺格意味着"仅 x64 CI 绿、
arm 用户装不上"的风险照不到。人工裁决（2026-11-13）：单开 change，
不塞进 `unify-coverage-gates`。

## 任务

1. 新建 OpenSpec change（建议名 `add-linux-arm64-binding-cells`）。
2. `ci.yml`：python job 与 node job 各加一格
   `os: ubuntu-26.04-arm`，只跑最新语言版（python 3.15 / node 26），
   步骤链照抄现有 ubuntu 格（node 含 wasm+native+check:cross 全套），
   与 windows/macos"验 ABI 不验版本 spread"口径对齐。
3. ci-matrix spec「硬件平台轴」同步补一句：python/node 另在 linux-arm64
   各跑最新一格验 aarch64 ABI（LL-034 波及面同步）。

## 注意事项

- 覆盖率报告路径固定（`coverage/coverage-native.json` 等），多 OS 格并行
  会互相覆盖：若届时需逐平台留存报告，报告名须带 matrix 标识；
  地板为 0 的标定轮不受影响（打印即可）。
- arm64 runner 为 `ubuntu-26.04-arm`（rust/wasm job 已在用，模式现成）。

## 去向
